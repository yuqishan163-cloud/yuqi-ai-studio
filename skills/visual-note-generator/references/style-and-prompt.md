# 默认视觉与提示词规范

## 视觉风格

- 专业的学霸手绘读书笔记（Sketchnote），不要幼儿卡通感。
- 米白纸张与轻微纸纹；海军蓝 `#1E3A8A`、浅蓝 `#60A5FA`、橙黄或金色 `#F59E0B` 为主色。
- 轻微水彩、彩铅填色和柔和深棕或海军蓝手绘轮廓，线条可略有自然抖动。
- 中文标题使用粗手写艺术字，正文使用清晰自然的个人笔记手写体；可读性高于装饰性。
- 使用少量书本、灯泡、放大镜、铅笔、图钉、对话框、核对符号、箭头和虚线框组织信息。

## 版式

- 竖版 3:4，所有信息在一页内完成。
- 顶部标题约占 15%～20%；中部是主要信息；底部放模板、流程或金句。
- 主体优先使用 2×2、2×3 卡片网格或单向流程，不混用过多结构。
- 每个区块留白充分；不通过缩小字号容纳过量文字。

## 生成提示词骨架

```text
Use case: infographic-diagram
Asset type: 中文竖版社交媒体知识卡片，3:4，高清
Input images: 默认风格参考图；用户参考图（如有）
Primary request: 把已锁定的中文底稿制作成一张完整、清晰、可收藏的手绘知识卡片。
Style/medium: 专业学霸手绘 Sketchnote，米白纸纹，海军蓝、浅蓝、橙黄、金色水彩和彩铅质感；自然手绘轮廓，不要儿童卡通感。
Composition: 顶部醒目标题；中部 3～5 个同类知识区块；底部模板或行动流程与一句总结。层级清晰，留白充足。
Text (verbatim):
<粘贴最终中文底稿>
Constraints: 只出现上述文字；所有中文清晰可读；标题与关键词加粗；不得遗漏、重写或重复；不要品牌标志、水印、乱码或额外说明。
```

## 质量门槛

生成后逐项检查：

1. 一张图是否只讲一条主线。
2. 3 秒内能否看懂标题和核心结论。
3. 中文是否逐字准确、无乱码。
4. 正文在手机屏幕上是否可读。
5. 同层级区块是否保持同类、同粒度。
6. 图标是否辅助理解而非占据版面。
7. 是否存在被截断、超框或互相遮挡的元素。

如第 1、3、4、7 项不合格，必须修改后再交付。
